# Голосовой читатель для Google Chrome

Расширение озвучивает выделенный текст. Работает на Manifest V3, не требует Node.js, npm, сервера или регистрации.

## Установка (Ubuntu / Windows / macOS)

1. Распакуйте ZIP в отдельную папку, например `selected-text-reader`.
2. Откройте Google Chrome и перейдите на `chrome://extensions`.
3. Включите **«Режим разработчика»** (Developer mode) справа вверху.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку **selected-text-reader** — ту, в которой находится `manifest.json`.
6. Закрепите расширение в меню с иконкой пазла, если удобно.

**ZIP-файл нельзя выбирать напрямую** при установке через Load unpacked: сначала распакуйте его.

## Использование

- **Через меню:** выделите слова на веб-странице → правая кнопка мыши → **«🔊 Прочитать выделенный текст»**.
- **Через иконку:** выделите текст → откройте расширение → нажмите **«Читать»**. Можно вместо выделения вставить свой текст в поле.
- **С клавиатуры:** `Ctrl+Shift+8` — прочитать выделение, `Ctrl+Shift+9` — остановить. При конфликте горячих клавиш измените их на `chrome://extensions/shortcuts`.
- **Управление:** в окне есть пауза, продолжение, остановка, выбор скорости, языка и доступного голоса.

## Ubuntu и доступные голоса

Chrome TTS предоставляет системные или установленные в браузере голоса. На Linux встроенного TTS-движка Chrome может не быть. Поэтому добавлен альтернативный **«Веб-движок»** (Web Speech API). Режим «Автоматически» сначала ищет голоса Chrome TTS, а если их нет, использует веб-движок.

Если ни одного голоса нет или звук не воспроизводится:

1. Откройте расширение и выберите **«Веб-движок»** в настройках.
2. Проверьте, есть ли голоса в выпадающем списке.
3. Если оба движка без голосов, нужен совместимый с Chrome движок озвучивания (например, расширение с поддержкой Chrome TTS); установка `espeak-ng` **сама по себе не гарантирует**, что Chrome увидит голос.
4. Проверьте системный звук и попробуйте другую страницу.

Русский и армянский текст определяются приблизительно по алфавиту. Для естественного произношения язык должен поддерживаться выбранным голосом; наличие армянского голоса не гарантируется.

## Ограничения

- Не читает текст из изображения без OCR.
- Не получает выделение из служебных страниц `chrome://...`, страницы Chrome Web Store и некоторых защищённых вкладок; можно скопировать текст вручную в поле.
- Встроенный просмотрщик PDF и некоторые редакторы могут не отдавать выделение через кнопку/клавиатуру. Для них используйте контекстное меню или вставку текста.
- Длина текста за один запуск не больше 60 000 символов.
- Успех озвучивания зависит от доступности TTS-движка и голосов в браузере/системе. Вариант с Web Speech может зависеть от сетевого синтеза выбранного голоса.

## Конфиденциальность

Расширение само не отправляет текст на внешние сайты или API и не хранит историю прочитанного. Настройки скорости, языка и голоса хранятся локально в Chrome. Однако установленный речевой движок или облачный голос браузера может отправлять текст поставщику синтеза — это зависит от конкретного голоса.

## Структура

- `manifest.json` — конфигурация Manifest V3.
- `background.js` — меню, горячие клавиши, чтение выделения и Chrome TTS.
- `offscreen.html`, `offscreen.js` — Web Speech при закрытом окне расширения.
- `popup.html`, `popup.css`, `popup.js` — интерфейс и настройки.
- `icons/` — иконки.

Сборка не требуется. После ручных изменений на `chrome://extensions` нажмите **«Обновить»** на карточке расширения.
