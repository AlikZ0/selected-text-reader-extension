# Голосовой читатель 2.0 для Google Chrome

Расширение для озвучивания выделенного текста и основного текста страницы. **Manifest V3**, без Node.js, npm, учётной записи или сервера.

## Что изменилось в 2.0

- Современный интерфейс, светлая / тёмная / системная темы.
- «Выделение» — взять текст, который выделен на активной странице.
- «Вся статья» — попытаться извлечь основной текст статьи (article/main). Это эвристика, не полноценный Reader Mode.
- Плеер: читать, пауза/продолжить, остановить, на фрагмент назад/вперёд.
- Прогресс по фрагментам (это не точная позиция внутри слова).
- Скорость 0.5–2.5×, тон и громкость (эффект зависит от установленного речевого движка).
- Русский, английский, армянский при наличии совместимых голосов, выбор голоса и движка (Chrome TTS / Web Speech API).
- До 12 сохранённых вручную текстов в локальном хранилище браузера, без автоматической истории.
- Примерное время чтения, число слов, индикатор состояния на иконке.
- Контекстное меню для выделения и страницы, горячие клавиши.

## Установка / обновление

1. Распакуйте ZIP в папку `selected-text-reader-v2`.
2. В Chrome откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
5. Закрепите иконку расширения для быстрого доступа.

Если уже установлена версия 1.0 и нужно **сохранить её настройки**, лучше заменить файлы *в прежней папке* содержимым новой версии и нажать **Обновить** на `chrome://extensions`. При установке новой папки как нового расширения старые сохранённые настройки не перенесутся автоматически. При этом переключение версии 1→2 сохраняет базовые настройки, а новые берутся по умолчанию.

## Как пользоваться

- Выделите текст на странице → **правая кнопка мыши → «🔊 Прочитать выделение»**.
- Кликните по иконке → **«Выделение»**, затем **«Читать»**.
- Для статьи нажмите **«Вся статья»**. Извлечение работает не на всех сайтах; если страница сложная, выделите нужный текст вручную.
- Можете вставить свой текст в поле и нажать **«Читать»**.
- Кнопки слева/справа от паузы переключают **фрагменты**, примерно по 240 символов, а не отдельные слова.
- Кнопка «Сохранить» добавляет текущий текст в раздел «Сохранённые тексты». Можно открыть его позже и удалить. Лимит — 12 текстов, при добавлении 13-го самый старый удаляется.
- `Ctrl+Shift+8`: чтение выделения. `Ctrl+Shift+9`: остановить. Изменение комбинаций — `chrome://extensions/shortcuts`.

Изменения скорости, тона, громкости и голоса вступают в силу при **следующем запуске** чтения.

## Голоса на Ubuntu/Linux

Chrome TTS может не обнаружить встроенных голосов. Резервный путь — **Web Speech API** (режим «Web Speech» в дополнительных настройках). Если оба списка голосов пусты, расширение не сможет озвучивать текст, пока в браузере не появится совместимый речевой движок.

Для русского и армянского корректное произношение зависит от поддержки языка самим голосом. Расширение не предоставляет и не загружает собственные голоса. Web Speech в некоторых конфигурациях может использовать облачный голос, поэтому не гарантируется полностью автономная работа или отсутствие передачи текста поставщику голоса.

## Доступ и ограничения

- Нет постоянного разрешения на чтение всех сайтов. Используются `activeTab` + `scripting` после действия пользователя, `tts`, `offscreen`, `storage` и `contextMenus`.
- Расширение само не отправляет тексты на собственный сервер и не содержит аналитики. Но выбранный речевой движок может использовать сетевой синтез речи.
- Сохранённые вручную тексты лежат в `chrome.storage.local`. Текущий текст читается из временного `chrome.storage.session` во время воспроизведения. История прочитанного автоматически не ведётся.
- Не извлекает текст из скриншотов / изображений (OCR нет), не озвучивает защищённые системные страницы Chrome и некоторые PDF/редакторы.
- Прогресс приблизителен и зависит от фрагментов; после завершения чтения достигает 100%.
- При запуске до 60 000 символов. Сохранённые тексты расходуют место в локальном хранилище (в Chrome local storage стандартная квота — около 10 MB, расширение может выдать ошибку при переполнении).
- Если popup закрывается, синтез должен продолжаться в фоне при наличии совместимого TTS-движка. Некоторые Web Speech реализации на Linux ведут себя иначе.

## Структура

- `manifest.json` — настройки расширения.
- `background.js` — доступ к странице, меню, очередь Chrome TTS, прогресс и команды.
- `offscreen.html`, `offscreen.js` — альтернативное озвучивание через Web Speech API.
- `popup.html`, `popup.css`, `popup.js` — интерфейс, настройки, библиотека.
- `icons/` — иконки расширения.

Исходники включены. Команда сборки не нужна.

## Техническая проверка

Проверены JSON, синтаксис JavaScript и основные UI-сценарии через Chromium с имитацией API расширения. Полный браузерный запуск и звук на реальном устройстве не подтверждены; после установки проверьте чтение короткого текста и доступность голосов.
